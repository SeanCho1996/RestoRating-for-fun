# Newmarket 食评

一个零第三方依赖的中文校园餐厅评分网站。包含邮箱验证、管理员/普通用户权限、餐厅图片管理，以及“先评分，后查看平均分”的评分机制。

## 运行

需要 Node.js 20 或以上版本。

```bash
cp .env.example .env
npm start
```

打开 <http://localhost:35774>。应用启动时会自动读取 `.env`。数据会保存在 `data/database.json`，上传的图片保存在 `uploads/`。

普通用户从网页注册；管理员不能通过公开注册创建，只能通过部署环境中的 `ADMIN_EMAIL` 和 `ADMIN_PASSWORD` 初始化。首次启动后，即使环境变量里的密码发生变化，也不会覆盖数据库中已有管理员的密码。

## 配置真实邮箱验证

复制 `.env.example` 中的变量到你的部署平台或 shell 环境。应用使用加密的 SMTPS 连接发送邮件，建议为 Gmail、Outlook、学校邮箱或其他 SMTP 服务创建专用的“应用密码”。关键配置如下：

- `BASE_URL`：用户能够访问的完整公开地址，例如 `https://rating.example.edu`。验证邮件会使用它生成链接。
- `SMTP_HOST`、`SMTP_PORT=465`、`SMTP_SECURE=true`：邮件服务器配置。
- `SMTP_USER`、`SMTP_PASS`：SMTP 登录账号与应用密码。
- `SMTP_FROM`：发件人邮箱。
- `NODE_ENV=production`：生产环境会给登录 Cookie 加上 `Secure`，并且不会在接口中返回开发验证链接。

如果开发环境没有配置 SMTP，验证链接会显示在服务器终端，并在注册成功提示中提供快捷入口。生产部署应始终配置 SMTP 和 HTTPS。

> `.env` 已被 Git 忽略；请勿提交真实密码。部署平台设置的环境变量可以覆盖本地配置。

## 权限与评分规则

- 管理员：添加、编辑和删除餐厅；餐厅必须有名称与照片；可以查看所有餐厅统计，但不能参与评分。
- 普通用户：仅可使用 `@aucklanduni.ac.nz` 奥大学生邮箱注册，必须验证邮箱后登录；可以评分及修改自己的评分。
- 密码重置：用户可在登录框申请 1 小时有效的一次性邮件链接，重置成功后已有会话会被注销。
- 查看排名：登录用户可以查看所有餐厅的平均分与等级，未登录访客不能查看统计。
- 五档评分：`5 夯`、`4 顶级`、`3 人上人`、`2 NPC`、`1 拉完了`。
